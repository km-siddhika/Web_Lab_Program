# P1 – Project folder and terminal navigation

**Aim:** Create a project folder and practise moving around using terminal commands.

```bash
mkdir my-portfolio
cd my-portfolio
mkdir images css
touch index.html
pwd
ls
cd css
cd ..
```

**Command notes**
- `mkdir` creates a directory.
- `cd` changes the current directory.
- `pwd` displays the current directory path.
- `ls` lists the files and folders.

**Check:** Run `pwd` and `ls` to confirm that the folders were created in the right place.
